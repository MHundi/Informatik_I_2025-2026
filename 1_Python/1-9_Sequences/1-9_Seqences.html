11.1 Tupel

  • Sequenz von Objekten
  • es können beliebige Objekte sein, auch andere Tupel und Listen
  • unveränderlich: Ein Tupel ändert sich nie, es enthält immer dieselben Objekte in der selben Reihenfolge.
  • aber: die enthaltenen Objekte können sich ändern.

Syntax:

Variablenname = (Obkjekt 0, Objekt 1, ... , Objekt n-1)

oder wenn keine Mehrdeutigkeiten entstehen auch ohne Klammern:

Variablennema = Objekt 0, Objekt 1, ..., Objekt n-1)

Beispiel 1:

myfirsttuple = (2,3,5,7,11)
print (myfirsttuple)
(2, 3, 5, 7, 11)

Beispiel 2:

mysecondtuple = 2,4,6,8,10
print(mysecondtuple)
(2, 4, 6, 8, 10)

Beispiel 3:

thirdtuple = ((1,6),(2,4),(3,4))
print(thirdtuple)
((1, 6), (2, 4), (3, 4))

Beispiel 4:

myforthtuple = (20,"Hallo")
print(myforthtuple)
(20, 'HAllo')

Beipsiel 5: Einelementiges Tupel

tryonetupel=(14)
print(tryonetupel)
14
(14,)
  1. wird als Integer interpretiert, da die Klammern hier nicht zur Tupelbildung sondern zur Gruppierung von Ausdrücken dienen.

Daher

onetuple = (14,)
print(onetuple)

Beispiel 6: Leeres Tupel: ()

()
()

Beipsiel 7: Tupel ohne Klammern (NICHT EMPFOHLEN)

anytuple = 2,4,6,8,10

11.2 Listen

  • eine Sequenz von Objekten
  • es können beliebige Objekte sein, auch andere Tupel und Listen
  • Elemente können angehängt, eingefügt oder entfernt werden.

Syntax:

Variablenname = [Objekt 0, Objekt 1, ... , Objekt n-1]

Beispiel 8:

myfirstlist = [3, 5, 7, 9]
print(myfirstlist) 
[3, 5, 7, 9]

Tupel und Listen können beliebige Objekte enthalten, auch andere Tupel und Listen.

Biepsiel 9: Verschachtelte Tupel und Listen

([18,20,"weg"],[("Kreuz", [])])
([18, 20, 'weg'], [('Kreuz', [])])
[23,"green"]
[23, 'green']

11.3 Tuple Unpacking

  • entspricht komponentenweise Zuweisung von Tupeln
    • kleine Form von Pattern Matching
  • funktioniert mit Listen und Strings etc.

Beispiel 10:

a, b = 2, 3
print(a)
print(b)
2
3

Gleichwertig zu

a = 2
b = 3
a,b,c =[3,5,8]
print(a)
print(b)
print(c)
3
5
8

Aber Vorteil bei der Mehrfachzuweisung ist: Die Zuweisung erfolgt gleichzeitig. Damit kann man vertauschen:

a,b=2,3
print ("a ist ", a, "b ist ", b)
a, b = b,a
print ("a ist ", a, "b ist ", b)
a ist  2 b ist  3
a ist  3 b ist  2

Beispiel 11:

[a, (b,c), (d,e),f]= (42, (6,9), "do", [1,2,3])

print(a , " | ", b, " | ", c ," | ", d, " | ", e, " | ",f )
42  |  6  |  9  |  d  |  o  |  [1, 2, 3]

11.5 Operationen auf Sequenzen

Verkettung: "Hallo " + "Kurs" == ""Hallo Kurs"

Wiederholung: 2*"Hallo " == "Hallo Hallo "

Indizierung: "Python"[1] == "y"

Mitgliedschaftstest: 11 in [2,3,5,7,11,13,17]

Slicing: "Friedrich Gymnasium"[10:18] == "Gymnasium"

Typkonvertierung list("Hallo")=["H", "a", "l", "l", "o"]

Iteration: for x in "python"

11.5.4 Test auf Mitgliedschaft

  • Testen, ob ein Element in einer Sequenz enthalten ist
  • in-Operator
  • Syntax: item in seq
  • True, wenn seq das Element item enthält
  • seq muss Tupel oder Liste sein
  • ist seqein String, sucht der Operator ineinen Substring
  • Syntax: substring in string

Beispiel 15:

print(2 in [1,2,4])

if "pizza" in ("Ei", "Omlette", "Croissant"):
    print("lecker")
True
print("i" in "pizza", "pozz" in "pizza", "izza" in "pizza")
True False True

11.5.5 Slicing

  • Teile ausschneiden
  • Syntax: seq[start:end]

Beispiel 16:

primes = (2,3,5,7,11,13, 17, 19)

#beginnt an der 2 Position (Position 1) und hört vor Position 4 auf
print(primes[1:4])

#beginnt am Anfang und geht bist vor die Position 2 
print(primes[:2])

# drittletzte Position bis Ende
print(primes[-3:])

#von Anfang bis Ende
print(primes[:])
(3, 5, 7)
(2, 3)
(13, 17, 19)
(2, 3, 5, 7, 11, 13, 17, 19)

Bemerkung:

  • Beim Slicing gibt es keine Indexfehler. Bereiche außerhalb sind einfach leer.
  • Slicing kann auch von hinten indiziert werden: seq[-start:-end] oder seq[-start:] oder seq[:-end]
primes[2:10]
(13, 17, 19)
primes[-3:]

11.5.6 Typkonvertierung:

  • tuple-Operator wandelt eine Liste in ein Tupel um
  • list-Operator wandelt ein Tupel in eine Liste um
  • str-Operator wandelt in eine “Druckversion”
# Liste in Tupel umwandeln
tuple([2,4,6])
(2, 4, 6)
#Tupel in eine Liste umwandeln
list((3,5,7))
[3, 5, 7]
#gibt eine ausgedruckte Repräsentation zurück
str(["a", "b", "c"])
"['a', 'b', 'c']"
list("Happy New Year")
['H', 'a', 'p', 'p', 'y', ' ', 'N', 'e', 'w', ' ', 'Y', 'e', 'a', 'r']
tuple('thank you') 
('t', 'h', 'a', 'n', 'k', ' ', 'y', 'o', 'u')

11.5.7 Liste zu einem String zusammenfügen

  • join-Operator
  • Anwendung auf einen leeren String
  • einzelne Elemente einer Sequenz werden zu einem String zusammenfeführt

Beispiel 17:

#Liste von Strings wieder in einen String überführen, "" ist leerer String
"".join(["h", "e", "l","l", "o"])
'hello'
#Tupel von Strings in einem String zusammenführen, angewandt auf ein nicht leeren String
"*".join(("t","o","p"))
't*o*p'

11.5.9 Minimum bzw. Maximum einer Sequenz berechnen

  • min-Operator, oder max-Operator
  • gibt das Minimum oder Maximum einer Sequenz an.
  • besteht die Liste selbst aus Sequenzen, dann wird die lexikographische Ordnung verwendet.
  • nicht vergleichbare Typen führen zu einer Fehlermeldung

Beispiel 19:

min([6,13,65,2,34,-2])
-2
max([6,13,65,2,34,-2])
65
min(("ah", "beh", "ce", "de"))
'ah'
